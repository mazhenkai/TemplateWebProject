# log/

运行期日志与运行产物。**不进 git**（`.gitignore` 已忽略本目录除本 README 外的全部内容）。

> 注意区分：`log/` 是**程序**写的运行日志；`doc/log/` 是**人**写的开发日志。

## 建议结构

```
log/
├── backend_dev.log
├── backend_prd.log
└── archive/
    └── 260126/       按天归档 YYMMDD
```

## 约定

1. **日志不记录密钥**：`Authorization` 头、口令、token 脱敏为 `***`。
2. **失败也要记**：错误响应、超时、连接中断同样是排查依据。
3. **按天归档**：启动脚本可在开工时把前一天的日志移入 `archive/YYMMDD/`。
4. **清理由人决定**：可以写归档，不写自动删除。
