# data/

本地散装数据文件：导入前的原始数据、样本文件、导出结果。**默认不进 git**（`.gitignore` 已忽略本目录除本 README 外的全部内容）。

## 与相邻目录的区别

| 目录 | 放什么 | 一句话 |
|---|---|---|
| `data/`（本目录） | 人工准备或导出的数据 | 喂进去的 / 导出来的 |
| `log/` | 程序运行自动产生的日志 | 吐出来的 |
| `config/` | 影响运行行为的配置 | 怎么跑 |

## 约定

1. **保留来源**：每批数据在同目录放一个说明（或在文件名里体现），写清从哪来、什么时候、怎么得到的。
2. **大文件、私密数据、用户数据不入库**。确需入库的小样本用 `git add -f` 显式添加，并在 commit 正文说明原因。
3. 能由代码生成的数据（固定 seed）不存文件。
