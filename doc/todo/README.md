# doc/todo/

**已确认需要做、但当前阶段暂缓**的事项。评审、开发过程中冒出来的"以后再说"都记这里，不要只在对话里说一句。

命名：`YYMMDDHHmm_主题.md`，一个文件一批，如 `2601200230_代码评审暂缓项.md`。

## 每项至少写清

```markdown
## 1. <一句话标题>

- **是什么**：问题现象，指向代码位置 / 文档章节
- **为什么暂缓**：当前不做的理由
- **影响范围**：不做会在什么情况下出错
- **什么时候必须做**：触发条件（如「上线评论功能之前」）
```

## 约定

- 完成后在条目标 ✅ 并写对应 commit hash；整批完成后文件保留，不删。
- 某项决定不做了，标 ❌ 并写理由。
- 开始做某项时，如果工作量大，先在 `plan/` 写计划，并在条目里链接过去。
