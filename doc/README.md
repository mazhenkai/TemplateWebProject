# Docs/

全部项目文档，按生命周期分目录。另见根目录 `README.md` 的目录树。

## 约定

- **命名带时间戳前缀**：`YYMMDDHHMM标题.md`，如 `2610071347产品规划.md`。时间戳取文档创建时间，便于排序和追溯。
- **生命周期**：`plan/`（进行中）→ 完成并归档 → `complete/`；废稿 → `archive/`。
- **日志按天/按次记**：`log/` 里按时间戳命名，如 `2610071516开发日志.md`。
- 账号、口令、命令清单等操作信息放 `Docs/readme.md`（注意与根 `README.md` 区分：根 README 讲结构，Docs/readme.md 讲操作）。
