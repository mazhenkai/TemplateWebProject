```bash

# 前端检查
cd frontend && npm run lint && npx tsc --noEmit

# 后端检查
# <如 cd backend && go vet ./... && go test ./...>

# 提交前检查
bash opt/linux/check.sh
```

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `$'\r': command not found` | `.sh` 被转成了 CRLF | `.gitattributes` 已约束；已损坏的文件用 `sed -i 's/\r$//' xxx.sh` 修复 |
| 端口被占用 | 旧进程未退出 | `ss -ltnp \| grep <端口>` 找到后停止 |
