# 项目阅读说明

> 更新时间：2026-11-26
> 给第一次接手项目的人（包括 AI 助手）。复制模板后按项目实际补全。

## 1. 建议阅读顺序

1. 根 `README.md`：目录导航、环境与端口、核心约束
2. `doc/README.md`：文档体系怎么组织
3. `doc/doc/开发环境说明.md`：怎么把项目跑起来
4. `doc/plan/` 中状态为 🚧 的计划：现在在做什么
5. `doc/log/` 最近 3 篇：最近做了什么、卡在哪
6. `doc/todo/`：欠着什么
7. 要改哪个目录，就读那个目录的 `README.md`

## 2. 代码与环境对应关系

| 环境 | 代码位置 | 前端 | 后端 | 数据库 |
|---|---|---|---|---|
| dev | <路径> | <端口> | <端口> | `dev` schema |
| prd | <路径或构建产物位置> | <端口> | <端口> | `prd` schema |

## 3. 后端调用链

```
请求 → middleware（鉴权、日志） → handler（参数校验） → service（业务） → repository（SQL） → 数据库
```

找一个接口的实现：从路由注册处找到 handler，再顺着往下读。

## 4. 前端结构

```
页面路由 → 组件 → src/lib 接口封装 → 后端 API
```

## 5. 修改前检查

- [ ] 读过要改的目录的 `README.md`
- [ ] 改动较大时已在 `doc/plan/` 写了计划
- [ ] 涉及建表时看过 `建表规范.md`
- [ ] 知道怎么验证：跑哪些测试、访问哪个页面
